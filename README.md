# Suspicious URL Detection in IoT Environment

## Project Overview
This project focuses on predicting suspicious URLs in IoT environments using a hybrid feature selection technique and machine learning.

## Project Objectives
- Identify suspicious URLs using machine learning.
- Extract relevant URL features.
- Apply a hybrid feature selection approach.
- Train and evaluate prediction models.

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Project Workflow
1. Dataset Collection
2. Data Preprocessing
3. URL Feature Extraction
4. Hybrid Feature Selection
5. Machine Learning Model Training
6. Model Evaluation
